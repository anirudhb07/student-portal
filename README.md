# Student Portal

A simple C++ project demonstrating Git and GitHub workflow.

## Prerequisites

Before running the project, make sure the following are installed:

- Git
- GCC/G++
- A GitHub account

## Setup

Clone the repository :

```bash
git clone https://github.com/anirudhb07/student-portal.git
cd student-portal
```

## Compilation

Compile the C++ program using:

```bash
g++ main.cpp -o main
```

## Running the Program

After compiling the program, run it with:

```bash
./main
```
